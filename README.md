# Учебные проекты

Репозиторий содержит три части:

- `task_1` — консольный генератор случайных паролей на C++;
- `test` — игра «Змейка» на C++/SDL2, собранная в WebAssembly через Emscripten;
- `task_2` — Telegram-бот на Python и aiogram, который открывает веб-игру.

## task_1: генератор паролей

Перейдите в папку проекта и соберите программу:

```bash
g++ -std=c++17 main.cpp -o main
```

Запустите её:

```bash
./main
```

Программа попросит длину пароля. Допустимый диапазон — от 1 до 4096 символов.

## task_2: Telegram-бот

### Запуск через Docker

Перейдите в папку `task_2`:

В `.env` укажите действительный токен:

```env
BOT_TOKEN=токен_бота_от_BotFather
```

Соберите образ и запустите контейнер в фоне:

```bash
docker compose up -d --build
```

Остановите бота:

```bash
docker compose down
```
